## Как сдавать

Работа сдаётся пул-реквестом. Если всё новое — просто делайте по шагам, здесь ровно шесть команд.

**1. Форкните репозиторий.** Кнопка **Fork** справа вверху на этой странице.

**2. Склонируйте свой форк** (адрес возьмите из зелёной кнопки Code на своём форке):

```bash
git clone https://github.com/ВАШ-ЛОГИН/js-kontrolnaya.git
cd js-kontrolnaya
```

**3. Создайте ветку.** Имя — ваша фамилия латиницей:

```bash
git checkout -b ivanov
```

**4. Решайте.** Ответы на части A и C пишите в `ОТВЕТЫ.md`, код части B чините в `task/script.js`.

**5. Закоммитьте и запушьте:**

```bash
git add .
git commit -m "Контрольная: Иванов, группа 11-901"
git push origin ivanov
```

**6. Откройте пул-реквест внутри своего форка:** ветка `ivanov` → ветка `main` **вашего же форка**.
GitHub предложит это сам после пуша. Ссылку на пул-реквест пришлите преподавателю.

> Пул-реквест делаем **в свой форк**, а не в этот репозиторий. Так ваша работа видна только вам и мне.

**Если git не заработал** — не тратьте на него время. Присылайте папку архивом в чат, балл за это не снижается. Разберёмся с git отдельно.

## Часть A. Почему так · 3 вопроса по 0,5 балла · 1,5 балла

Результат работы программы уже написан в комментарии. Запускать не нужно — объясните, **почему** получилось именно так. Два-три предложения на вопрос.

Ответы пишите в `ОТВЕТЫ.md`.

### A1

```js
const a = { n: 1 };
const b = a;

b.n = 2;

console.log(a.n);   // 2
```

Значение меняли у `b`, а изменилось и у `a`. Почему?

### A2

```js
console.log("1");

setTimeout(() => console.log("2"), 0);

Promise.resolve().then(() => console.log("3"));

console.log("4");

// в консоли: 1 4 3 2
```

Вызов `setTimeout` написан в коде выше, чем промис, а `3` выводится раньше `2`. Почему?

### A3

```js
const counter = {
  n: 0,
  add: () => {
    this.n += 1;
  },
};

counter.add();

console.log(counter.n);   // 0
```

Метод вызвали, ошибки в консоли нет, а счётчик остался нулём. Почему?

## Часть C. Обоснуйте выбор · 2 вопроса по 0,5 балла · 1 балл

В каждом вопросе оба варианта рабочие: страница не падает ни с одним из них. Выберите один и назовите **минимум две причины**.

### C1

Карточка в списке должна открывать отдельную страницу. Два способа:

```html
<div class="card" onclick="location.href='item.html?id=7'">Название</div>
```

```html
<a class="card" href="item.html?id=7">Название</a>
```

Какой выберете и почему?

### C2

Нужно вывести на страницу список имён. Имена вводят сами пользователи сайта. Два способа:

```js
list.innerHTML = users.map((u) => `<li>${u.name}</li>`).join("");
```

```js
users.forEach((u) => {
  const li = document.createElement("li");
  li.textContent = u.name;
  list.append(li);
});
``` 

Какой выберете и почему?
